# ORBIT 2.0

A polished, mobile-first personal growth companion built with Expo, React Native and TypeScript.

## Features
- Warm, accessible dashboard with a visible orb illustration on web and the animated 3D planet on native
- Home, Explore, Goals and Profile tabs
- Add goals with category and duration
- Tap missions to mark them complete and update weekly progress
- Responsive web layout: compact phone-width experience and centered wide desktop layout
- Expo Router navigation entry and Expo-compatible SDK 57 dependency versions

## Run
```bash
npm install
npx expo start
```
For web, press `w` or run `npm run web`. For device testing, scan the QR code with a compatible Expo Go version.

## Notes
Mission state is currently in memory and resets on app reload. Authentication, persistent storage, backend sync and production testing are not yet implemented. The web orb is a layered visual fallback; the native build uses the animated React Three Fiber scene.
